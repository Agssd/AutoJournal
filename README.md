# Auto Journal — учёт автомобилей и расходов

Android-приложение для гаража: автомобили, история обслуживания, напоминания, расходы и документы. Тёмная тема, Jetpack Compose.

## Возможности
- Главная: авто пользователя + общие расходы (год, % к прошлому году, график 6 мес.)
- Гараж: список авто, добавление/редактирование/удаление с подтверждением
- Детали авто: госномер, VIN, год, пробег, цвет, табы История / Напоминания / Расходы
- Расходы: сумма за год, помесячный график (текущий месяц — оранжевый)

## Стек
- Kotlin, Jetpack Compose (Material3), Navigation Compose
- Room (Car, Expense, ServiceRecord), Coroutines + StateFlow
- Koin (DI), Coil (фото — позже), ML Kit OCR (план)
